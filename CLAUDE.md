# Project notes

This repo is a personal collection of algorithm/DSA problem solutions under
`Solutions/`.

## IMPORTANT: do not fix the solutions

When asked to write or run tests for a file under `Solutions/`:

- Only write and maintain **test code** (under `tests/`).
- Do **not** edit, "fix", or complete the solution file itself — even if it
  looks broken, incomplete, or has an obvious bug (e.g. a `pass` stub).
  Failing tests against incomplete code are expected and fine; that's the
  point of having tests.
- If a solution is genuinely unfinished, note that in your summary instead
  of patching it.

This rule applies to the whole repo, not just one file.
